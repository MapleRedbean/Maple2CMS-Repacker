# 2026-04-30 工作日志

## Orion2 Repacker 修复

### 问题描述
Zlib decompression 失败，错误信息：
```
Ver=0x4632534F (OS2F格式), BufferFlag=0xEE000009, IsShifted=False
Bad state (unknown compression method (0x89))
```

0x89 不是有效的 zlib 头，说明解密后数据是乱码，密钥偏移量计算错误。

### 根本原因
`DecryptData` 方法没有传递 `isShiftedLayout` 参数给 `Decrypt` 方法，导致 OS2F 文件使用错误的密钥偏移量。

### 修复方案

1. **IPackFileHeaderVerBase.cs** - 添加 `IsShiftedLayout` 属性
2. **PackFileHeaderVer1.cs** - 实现 `IsShiftedLayout` 属性（默认 false）
3. **PackFileHeaderVer2.cs** - 实现 `IsShiftedLayout` 属性（默认 false）
4. **PackFileHeaderVer3.cs** - 实现 `IsShiftedLayout` 属性
5. **MainWindow.cs** - 在创建 PackFileHeaderVer3 后设置 `IsShiftedLayout = pStream.GetIsShiftedLayout()`
6. **CreateItem.cs** - 同上
7. **CryptoMan.cs** - `DecryptData` 调用 `Decrypt(..., pHeader.IsShiftedLayout)`

### 文件修改清单
- `Crypto/Stream/PackFileHeaderVerBase.cs`
- `Crypto/Stream/PackFileHeaderVer1.cs`
- `Crypto/Stream/PackFileHeaderVer2.cs`
- `Crypto/Stream/PackFileHeaderVer3.cs`
- `Crypto/CryptoMan.cs`
- `Window/MainWindow.cs`
- `Window/CreateItem.cs`
